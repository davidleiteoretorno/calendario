# App de Produtividade Beta

Aplicação estática de planejamento semanal e acompanhamento mensal.

- `index.html` é a versão principal publicada pelo GitHub Pages.
- `historico/index-anterior.html` preserva a página que estava publicada antes da migração.
- `historico/versoes/` guarda os protótipos anteriores.
- `referencias/` reúne materiais locais de apoio e não é publicada no GitHub.

Os protótipos foram ordenados pelas datas de modificação dos arquivos locais e registrados em commits reconstruídos. As datas desses commits indicam a reconstrução, não a criação original de cada versão.

O `.gitignore` funciona como uma lista de permissões: mantém no repositório apenas a aplicação, a documentação e o histórico selecionado. Materiais pessoais e credenciais locais ficam fora do Git.
